### DWT消抖原理未说明
**改进步骤**:
1. 说明DWT计数器频率为168MHz（系统频率）
1. 计算公式：消抖周期 = 系统频率 × 消抖时间
1. 50ms消抖需要：168MHz × 0.05s = 8,400,000周期
1. 对比软件延时消抖会阻塞CPU的问题

**代码示例**:
```c
// DWT消抖原理与实现

// 1. DWT初始化（使能周期计数器）
void DWT_Init(void) {
    CoreDebug->DEMCR |= CoreDebug_DEMCR_TRCENA_Msk;  // 使能DWT
    DWT->CYCCNT = 0;                                  // 复位计数器
    DWT->CTRL |= DWT_CTRL_CYCCNTENA_Msk;             // 使能计数
}

// 2. 定义消抖周期数（50ms @ 168MHz）
// 计算公式：168,000,000 Hz × 0.05 s = 8,400,000
#define DEBOUNCE_CYCLES 8400000

// 3. 消抖检查函数
static uint32_t last_tick = 0;

int is_debounced(void) {
    uint32_t current = DWT->CYCCNT;
    // 检查是否超过消抖周期
    if ((current - last_tick) >= DEBOUNCE_CYCLES) {
        last_tick = current;
        return 1;  // 可以处理
    }
    return 0;  // 仍在消抖中
}

// DWT消抖优势：
// 1. 不阻塞CPU（不使用延时函数）
// 2. 精度高（基于硬件计数器）
// 3. 开销小（仅读取寄存器）
```

```c
// 2. 设置EXTI4优先级

// - 数值越小，优先级越高
// - 抢占优先级：可以打断低优先级中断
```

```c
// HAL库中的弱定义（在stm32f4xx_hal_gpio.c）
__weak void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin) {
    // 默认为空，用户可以重写
}

// 用户代码中重写
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin) {
    // 检查是否是KEY0按键
    if (GPIO_Pin == KEY0_Pin) {
        // 消抖检查
        if (is_debounced()) {
            // 执行状态切换
            Gear_Switch();
        }
    }
}

// 中断响应流程：
// 1. 按键按下触发EXTI中断
// 2. 进入EXTI4_IRQHandler()
// 3. HAL库处理清除中断标志
// 4. 调用HAL_GPIO_EXTI_Callback()
// 5. 执行用户代码
```
