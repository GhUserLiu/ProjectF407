# STM32 教学管理系统 - 发布包

## 版本信息

**版本**: 2.6.0
**发布日期**: 2024-06-12
**平台**: Windows 10/11 (x64)

## 快速开始

### 1. 首次运行

双击 `STM32教学管理系统.exe` 启动应用程序。

### 2. 项目配置

首次使用需要在设置页面配置项目：

- 班级名称
- 实验目录路径
- 提交目录路径
- 输出目录路径

### 3. 核心功能

- **查重检测**: ZIP 文件相似度检测
- **评分评估**: 基于 Rubric 的自动评分
- **反馈生成**: 个性化学生反馈
- **报告输出**: 多格式报告导出

## 系统要求

- **操作系统**: Windows 10/11 (64位)
- **内存**: 4GB RAM (推荐 8GB)
- **磁盘空间**: 200MB 可用空间
- **权限**: 可能需要管理员权限（取决于安装位置）

### 运行库依赖

本程序需要以下系统组件：

| 组件           | 说明                   | 下载链接                                           |
| -------------- | ---------------------- | -------------------------------------------------- |
| **VC++ 运行库** | Visual C++ 可再发行组件 | [微软下载中心](https://aka.ms/vs/17/release/vc_redist.x64.exe) |

如果启动时提示缺少 DLL 文件，请安装 VC++ 运行库。大多数 Windows 10/11 系统已预装。
