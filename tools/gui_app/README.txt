STM32教学管理系统 v2.6.0
========================

欢迎使用 STM32教学管理系统！

系统概述
--------
本系统是专为STM32嵌入式教学设计的综合管理工具，包含以下功能：

1. 查重检测 - 智能检测学生实验报告的相似度
2. 自动评分 - 根据评分标准自动生成成绩
3. 反馈生成 - 为学生提供详细的改进建议
4. 报告管理 - 生成Excel、PDF格式的成绩报告
5. 批量处理 - 支持批量处理多个班级的提交

安装目录
--------
默认安装位置：C:\Program Files\STM32教学管理系统\

如果您修改了安装位置，请记住您选择的路径。

安装目录结构
--------------
├── STM32教学管理系统.exe    # 主程序
├── config/                    # 配置文件目录
│   ├── config.yaml           # 主配置文件
│   └── security_config.json  # 安全配置
├── data/                      # 数据目录（重要！）
│   ├── rubrics/              # 评分标准（.json文件）
│   ├── templates/            # 报告模板（.docx/.md文件）
│   ├── test/                 # 测试数据（示例文件）
│   ├── students/             # 学生名单（需要添加您的学生）
│   ├── submissions/          # 学生提交（需要添加学生提交）
│   └── results/              # 处理结果输出目录
├── tools/                     # 工具脚本
├── logs/                      # 日志文件
└── temp/                      # 临时文件

快速开始
--------
方法一：使用安装目录的 data 文件夹（推荐）
1. 打开安装目录，进入 data 文件夹
2. 将学生名单（Excel格式）放入 data/students/ 目录
3. 将学生提交的ZIP文件放入 data/submissions/ 目录
4. 在程序中打开文件对话框时，会自动定位到 data 目录
5. 选择要处理的班级和实验，点击"开始处理"

方法二：使用自定义目录
1. 在程序设置中配置您的自定义路径
2. 程序会记住您最后使用的目录位置
3. 下次打开对话框时会自动定位到上次使用的位置

重要提示：文件对话框默认位置
--------------------------
当您在程序中点击"浏览"按钮选择文件时：
- 选择评分标准（Rubric）→ 自动打开 data\rubrics\ 目录
- 选择报告模板 → 自动打开 data\templates\ 目录
- 选择学生提交 → 自动打开 data\submissions\ 目录
- 保存结果报告 → 自动打开 data\results\ 目录

如果自动定位失败，请手动导航到安装目录下的 data 文件夹。

学生名单格式
------------
学生名单文件应使用Excel格式（.xlsx），包含以下列：

| 学号     | 姓名   | 班级       | 分组 |
|----------|--------|------------|------|
| 2023001 | 张三   | 汽服2302B  | 1    |
| 2023002 | 李四   | 汽服2302B  | 1    |

文件命名建议：班级名.xlsx（如：汽服2302B班.xlsx）
存放位置：data\students\

提交文件格式
------------
学生提交应为ZIP压缩包，包含以下内容：

- 实验报告（Word格式：.docx）
- 代码文件（C源码：.c）
- 可选：其他支持材料

ZIP文件命名格式：学号_姓名_实验名.zip
存放位置：data\submissions\

测试数据
--------
data\test\ 目录包含示例文件，您可以：
1. 查看这些文件了解正确的格式
2. 使用测试数据熟悉系统功能
3. 测试完成后删除或替换为实际数据

常见问题
--------
Q: 找不到安装目录怎么办？
A: 打开"此电脑"，进入 C:\Program Files\STM32教学管理系统

Q: 文件对话框没有自动定位到正确位置？
A:
  1. 确保已正确安装程序
  2. 检查注册表项是否存在
  3. 手动导航到安装目录的 data 文件夹
  4. 程序会记住您最后使用的位置

Q: 如何备份我的数据？
A: 定期复制 data 文件夹到其他位置，或使用程序中的"备份数据"功能

Q: 可以修改安装目录吗？
A: 可以，但建议使用默认位置以便程序自动定位文件

卸载说明
--------
卸载程序会询问是否保留数据文件：
- 选择"是" → 保留 data 文件夹中的所有数据
- 选择"否" → 删除所有文件（包括学生名单和提交记录）

建议在卸载前备份重要数据。
