# STM32教学管理系统 - GUI应用

一个用于STM32F407嵌入式教学的桌面GUI应用，集成查重检测、评分评估、反馈生成等教学工具。

## 功能特性

### 核心功能

- **📊 概览仪表盘** - 项目概览、快捷操作、状态监控
- **🔍 查重检测** - 多算法文本/代码相似度检测，实时进度显示
- **📝 评分评估** - 基于Rubric的智能评分系统，等级分布可视化
- **💬 反馈生成** - 个性化学生反馈生成，支持预览和编辑
- **📄 报告输出** - Excel/HTML/PDF多格式报告导出
- **⚙️ 设置管理** - 项目配置、查重参数、评分标准配置

### 查重检测功能

- ✅ 支持多种相似度算法（文本、代码、结构、语义）
- ✅ 可配置相似度阈值（可疑、高相似、抄袭）
- ✅ 模板内容智能过滤
- ✅ 跨组对比检测
- ✅ 实时进度显示和日志输出
- ✅ 结果高亮显示（颜色编码）

### 评分评估功能

- ✅ 基于Rubric的评分标准
- ✅ 技术要点检查
- ✅ 代码深度分析
- ✅ 等级分布可视化
- ✅ 学生评分详情查看
- ✅ 优势、不足、改进建议分析

### 反馈生成功能

- ✅ 多种反馈风格（详细、标准、简洁、鼓励、技术）
- ✅ Markdown实时预览
- ✅ 批量和单个生成
- ✅ 支持自定义编辑
- ✅ 多格式导出（MD、HTML、TXT）

### 报告输出功能

- ✅ 成绩报告（简明、详细、按等级分组）
- ✅ 查重报告（Excel、HTML、PDF）
- ✅ 统计分析（平均分、及格率、分布图）
- ✅ 一键导出所有报告

## 快速开始

### 环境要求

- Python 3.9 或更高版本
- Windows 10/11（推荐）
- 4GB+ 内存

### 安装依赖

```bash
# 进入应用目录
cd d:\4-Workspace\MCU_Research\project_test\NewProjectF407\tools\gui_app

# 安装依赖
pip install -r requirements.txt
```

### 运行应用

```bash
python main.py
```

### 打包为可执行文件

#### Windows
```bash
# 使用批处理脚本
build.bat

# 或手动执行
pip install pyinstaller
pyinstaller build.spec --clean --noconfirm
```

#### Linux/Mac
```bash
# 使用shell脚本
chmod +x build.sh
./build.sh

# 或手动执行
pip install pyinstaller
pyinstaller build.spec --clean --noconfirm
```

打包完成后，可执行文件位于 `dist/STM32教学管理系统.exe`

## 使用说明

### 1. 创建项目

1. 启动应用后，点击工具栏的 "📄 新建项目" 或概览页的 "📄 新建项目" 按钮
2. 在 "⚙️ 设置" 页面填写项目信息：
   - 班级名称
   - 实验类型
   - 实验目录
   - 提交目录
   - 输出目录
3. 配置查重和评分参数
4. 点击 "💾 保存设置"

### 2. 查重检测

1. 导航到 "🔍 查重检测" 页面
2. 选择学生提交的ZIP文件目录
3. 配置检测参数：
   - 可疑阈值：默认60%
   - 抄袭阈值：默认85%
   - 启用模板过滤
   - 启用语义检测
4. 点击 "🚀 开始检测"
5. 查看检测结果表格和统计信息

### 3. 评分评估

1. 导航到 "📝 评分评估" 页面
2. 选择或导入Rubric评分标准
3. 配置评分选项：
   - Rubric评分
   - 技术要点检查
   - 代码深度分析
   - 图像质量检测
4. 点击 "🚀 开始评分"
5. 查看评分结果和等级分布
6. 点击学生列表查看详情

### 4. 生成反馈

1. 导航到 "💬 反馈生成" 页面
2. 选择反馈风格：
   - 详细 - 完整的问题分析和建议
   - 标准 - 基本的反馈内容
   - 简洁 - 简明扼要的反馈
   - 鼓励 - 侧重鼓励和正面反馈
   - 技术 - 侧重技术问题分析
3. 选择输出格式（Markdown/HTML/文本）
4. 点击 "🚀 批量生成" 或选择单个学生生成
5. 预览和编辑反馈内容
6. 点击 "📤 导出" 保存反馈文件

### 5. 导出报告

1. 导航到 "📄 报告输出" 页面
2. 选择报告类型标签页：
   - **成绩报告**：选择报告类型（简明/详细/按等级）
   - **查重报告**：选择格式（Excel/HTML/PDF）
   - **统计分析**：查看统计数据和分布图
3. 配置报告选项
4. 点击 "🚀 生成报告"
5. 选择输出目录保存报告

## 常见问题

**Q: 打包后启动失败？**
A: 检查是否所有依赖都包含在 `build.spec` 中，查看控制台错误信息。确保 `tools` 目录和 `docs` 目录正确包含。

**Q: 找不到学生提交文件？**
A: 确保项目配置中的提交目录路径正确，ZIP文件命名符合规范（格式：学生姓名_学号.zip）。

**Q: 查重结果不准确？**
A: 调整相似度阈值和权重配置，上传正确的模板文件以启用模板过滤。

**Q: 评分结果为空？**
A: 确保选择了正确的Rubric文件，检查提交文件中是否包含有效的实验报告和答题记录。

**Q: 如何导入现有的Rubric？**
A: Rubric文件为JSON格式，可以通过设置页面的"Rubric文件"选项导入。
