# STM32教学管理系统 - 安装程序创建指南

## 概述

本指南说明如何为 STM32教学管理系统创建 Windows 安装程序。

## 前提条件

### 1. 安装 Inno Setup

Inno Setup 是一个免费的 Windows 安装程序制作工具。

**下载地址：** https://jrsoftware.org/isdl.php

**安装步骤：**
1. 下载 `isetup-x.x.x.exe` (快速安装推荐)
2. 运行安装程序，使用默认设置
3. 安装完成后重启命令提示符

### 2. 确认可执行文件已生成

确保已经生成了可执行文件：
```bash
cd tools/gui_app
python -m PyInstaller build.spec --clean --noconfirm
```

## 创建安装程序

### 方法1：使用批处理脚本（推荐）

双击运行 `build_installer.bat`，脚本会自动：
1. 检查 Inno Setup 是否安装
2. 验证可执行文件存在
3. 生成测试数据
4. 编译安装程序
5. 打开输出文件夹

### 方法2：手动编译

```bash
# 1. 进入 gui_app 目录
cd tools/gui_app

# 2. 生成测试数据
python create_test_data.py

# 3. 编译安装程序
iscc installer.iss

# 4. 输出文件在 installer_output 目录
```

## 自定义配置

### 修改安装脚本

编辑 `installer.iss` 文件可以自定义：

- `[Setup]` 部分：安装程序设置
- `[Files]` 部分：包含的文件
- `[Icons]` 部分：快捷方式设置
- `[Registry]` 部分：注册表项

### 修改默认安装目录

在 `[Setup]` 部分修改：
```ini
DefaultDirName={pf}\STM32教学管理系统
```

### 添加更多文件

在 `[Files]` 部分添加：
```ini
Source: "path\to\file"; DestDir: "{app}\target"; Flags: ignoreversion
```

## 常见问题

### Q: Inno Setup 未找到
A: 请先安装 Inno Setup: https://jrsoftware.org/isdl.php

### Q: 编译失败，提示找不到文件
A: 检查文件路径是否正确，确保所有源文件存在

### Q: 安装程序运行后程序无法启动
A: 检查是否缺少必要的依赖，如 Visual C++ 运行库

### Q: 如何添加更多测试数据
A: 编辑 `create_test_data.py` 添加更多学生和提交示例
