## 安装与启动

### Q1: 程序启动后闪退怎么办？

**A:** 可能的原因和解决方法：

1. **缺少 VC++ 运行库**
   - 下载安装 [VC++ 可再发行组件](https://aka.ms/vs/17/release/vc_redist.x64.exe)
   - 重启计算机

2. **杀毒软件拦截**
   - 将程序添加到杀软白名单
   - 临时禁用杀软测试

3. **权限问题**
   - 右键以管理员身份运行

### Q2: 双击程序没有反应？

**A:**
- 检查任务管理器是否有进程在运行
- 检查是否有防火墙阻止
- 尝试重新安装程序

### Q3: 可以在 macOS/Linux 上运行吗？

**A:** 当前版本仅支持 Windows。如需其他平台：
- 使用源代码运行：`python main.py`
- 等待跨平台版本发布

## 配置与设置

### Q4: 如何配置项目路径？

**A:** 步骤如下：

1. 点击左侧 **⚙️ 设置**
2. 在 **项目设置** 标签页填写：
   - 班级名称
   - 实验类型
   - 实验目录
   - 提交目录
   - 输出目录
3. 点击 **💾 保存设置**

### Q5: 如何导入/导出配置？

**A:**

**导出配置：**
1. 在设置页面点击 **📤 导出配置**
2. 选择保存位置和文件名
3. 配置保存为 JSON 文件

**导入配置：**
1. 在设置页面点击 **📥 导入配置**
2. 选择之前导出的 JSON 文件
3. 配置自动加载

### Q6: 如何备份数据？

**A:** 在设置页面点击 **💾 备份数据**，系统会：
- 打包项目配置
- 包含提交和输出目录
- 生成带时间戳的 ZIP 文件

### Q7: Rubric 文件格式是什么？

**A:** Rubric 文件为 JSON 格式，示例：

```json
{
  "experiment": "汽车档位模拟器",
  "total_score": 100,
  "criteria": [
    {
      "name": "功能实现",
      "weight": 40,
      "max_score": 40,
      "items": [
        {"name": "档位切换正确", "score": 15},
        {"name": "显示正确", "score": 15},
        {"name": "按键响应", "score": 10}
      ]
    }
  ]
}
```

## 查重检测

### Q8: 查重结果如何解读？

**A:** 相似度范围解读：

| 相似度 | 标记 | 颜色 | 建议操作 |
|--------|------|------|----------|
| 0-59% | 正常 | 绿色 | 无需处理 |
| 60-84% | 可疑 | 黄色 | 人工复核 |
| 85-100% | 抄袭 | 红色 | 进一步处理 |

### Q9: 为什么查重结果为空？

**A:** 可能的原因：

1. **提交目录为空** - 确认有学生 ZIP 文件
2. **命名不规范** - 检查 ZIP 文件命名格式
3. **文件损坏** - 确认 ZIP 文件可以正常解压
4. **模板过滤过度** - 降低阈值或关闭模板过滤

### Q10: 如何调整查重阈值？

**A:** 在设置页面的 **查重设置** 标签页：
- **可疑阈值**: 开始标记的相似度 (默认 60%)
- **抄袭阈值**: 确认抄袭的相似度 (默认 85%)

**调整建议：**
- 发现漏报 → 降低可疑阈值到 50%
- 发现误报 → 提高抄袭阈值到 90%

### Q11: 什么是语义相似度检测？

**A:** 语义检测使用深度学习模型检测改写内容：

- **文本相似度**: 检测完全相同的文字
- **语义相似度**: 检测意思相同但表述不同的内容

**注意：** 语义检测需要额外安装 `sentence-transformers` 库。

### Q12: 如何处理误报？

**A:** 误报处理方法：

1. 调整阈值参数
2. 上传模板文件启用过滤
3. 人工复核确认后，可在评分中手动调整

## 评分评估

### Q13: 评分等级如何划分？

**A:** 默认等级划分：

| 等级 | 分数范围 | 百分比 |
|------|----------|--------|
| A | 90-100 | 90-100% |
| B | 80-89 | 80-89% |
| C | 70-79 | 70-79% |
| D | 60-69 | 60-69% |
| F | 0-59 | 0-59% |

可在设置中自定义分数线。

### Q14: 如何自定义 Rubric 评分标准？

**A:** 步骤：

1. 准备 JSON 格式的 Rubric 文件
2. 在设置页面选择 Rubric 文件
3. 系统自动加载评分标准

### Q15: 评分结果为空或全部0分？

**A:** 检查：

1. Rubric 文件是否正确加载
2. 学生提交中是否包含实验报告
3. 提交文件格式是否正确（需要 DOCX）
4. 检查日志文件获取详细错误信息

### Q16: 技术要点检查是什么？

**A:** 技术要点检查根据实验类型自动检查：

- 是否使用了指定的外设
- 是否实现了必要的功能
- 代码结构是否合理

需要在 Rubric 中定义技术要点。

## 反馈生成

### Q17: 反馈风格有什么区别？

**A:** 各风格特点：

| 风格 | 特点 | 适用场景 |
|------|------|----------|
| 详细 | 完整的问题分析和建议 | 需要深入指导 |
| 标准 | 基本的反馈内容 | 常规情况 |
| 简洁 | 简明扼要的反馈 | 快速浏览 |
| 鼓励 | 侧重鼓励和正面反馈 | 基础较弱学生 |
| 技术 | 侧重技术问题分析 | 技术改进 |

### Q18: 如何批量生成反馈？

**A:** 在反馈生成页面：

1. 选择反馈风格
2. 选择输出格式
3. 点击 **🚀 批量生成**
4. 等待处理完成
5. 点击 **📤 导出** 保存

### Q19: 反馈可以手动编辑吗？

**A:** 可以：

1. 在预览区域直接编辑 Markdown 内容
2. 编辑后导出保存
3. 支持导出为 MD、HTML、TXT 格式

## 报告输出

### Q20: 如何导出成绩报告？

**A:** 在报告输出页面：

1. 选择 **成绩报告** 标签页
2. 选择报告类型（简明/详细/按等级）
3. 点击 **🚀 生成报告**
4. 选择保存位置

### Q21: 报告格式有什么区别？

**A:** 各格式特点：

| 格式 | 特点 | 适用场景 |
|------|------|----------|
| Excel | 可编辑，包含详细数据 | 数据分析 |
| HTML | 可在浏览器查看 | 在线分享 |
| PDF | 可打印，正式文档 | 归档存档 |

### Q22: 统计分析包含什么内容？

**A:** 统计分析包含：

- 平均分、及格率
- 分数分布图
- 等级分布
- 相似度分布
- 高分/低分学生列表

## 错误处理

### Q23: 遇到 "找不到模块" 错误？

**A:** 解决方法：

1. 确认安装了所有依赖：`pip install -r requirements.txt`
2. 检查 Python 版本 (需要 3.9+)
3. 重新安装 PyInstaller：`pip install --upgrade pyinstaller`

### Q24: 文件对话框打开位置不对？

**A:** 系统会智能记忆上次使用的目录。如需重置：
- 关闭程序
- 删除配置文件中的目录记忆
- 重新启动

### Q25: 处理卡住或无响应？

**A:** 解决方法：

1. 检查是否有大量文件（处理时间较长）
2. 查看状态栏的进度提示
3. 检查日志文件
4. 如持续无响应，强制重启程序

### Q26: 如何查看详细日志？

**A:** 日志文件位置：

- Windows: `%APPDATA%/STM32教学管理系统/`
- 文件名: `stm32_manager.log`

可在设置中调整日志级别。
