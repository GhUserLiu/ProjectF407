## 示例提交说明

### 1. 正常提交 (张三_23071140101.zip)

**特点：**
- 原创内容
- 功能完整
- 代码规范

**包含文件：**
- 实验报告.docx
- main.c
- main.h

**预期结果：**
- 相似度：低 (<30%)
- 评分：A (90-100)

---

### 2. 可疑提交 (李四_23071140102.zip)

**特点：**
- 与模板高度相似
- 可能有部分复制

**包含文件：**
- 实验报告.docx
- main.c
- main.h

**预期结果：**
- 相似度：中等 (60-84%)
- 标记：可疑
- 评分：B 或 C

---

### 3. 抄袭示例 (王五_23071140103.zip)

**特点：**
- 与另一学生高度相似
- 代码几乎相同

**包含文件：**
- 实验报告.docx
- main.c
- main.h

**预期结果：**
- 相似度：高 (>85%)
- 标记：抄袭
- 评分：F 或需人工处理

---

### 4. 改写提交 (赵六_23071140104.zip)

**特点：**
- 内容与参考相似但经过改写
- 需要语义检测

**包含文件：**
- 实验报告.docx
- main.c
- main.h

**预期结果：**
- 文本相似度：中等
- 语义相似度：高
- 标记：需人工复核
