## 1. 系统简介

STM32 教学管理系统是一个专为嵌入式教学设计的综合性工具，集成以下核心功能：

| 功能模块 | 说明 |
|----------|------|
| **查重检测** | 检测学生提交报告的相似度，支持多种算法 |
| **评分评估** | 基于评分标准自动评分，生成详细分析 |
| **反馈生成** | 为学生生成个性化反馈意见 |
| **报告输出** | 导出各类统计和分析报告 |
| **多班级管理** | 同时处理多个班级的数据 |

## 3. 快速入门

### 3.1 创建第一个项目

**步骤 1：进入设置页面**

点击左侧导航的 **⚙️ 设置** 菜单。

**步骤 2：填写项目信息**

```
班级名称: 汽服2302B班
实验类型: 汽车档位模拟器设计
实验目录: D:\教学\2026春\07-car-gear
提交目录: D:\教学\2026春\07-car-gear\提交
输出目录: D:\教学\2026春\07-car-gear\结果
```

**步骤 3：配置查重参数**

```
可疑阈值: 60%
抄袭阈值: 85%
启用模板过滤: ✓
启用语义检测: ✓
```

**步骤 4：配置评分参数**

```
Rubric 文件: rubric.json
启用技术要点: ✓
启用代码分析: ✓
```

**步骤 5：保存配置**

点击 **💾 保存设置** 按钮。

### 3.2 运行第一次查重

1. 点击左侧 **🔍 查重检测**
2. 点击 **📁 选择提交目录**
3. 确认目录后点击 **🚀 开始检测**
4. 等待处理完成，查看结果

### 3.3 生成第一次评分

1. 点击左侧 **📝 评分评估**
2. 确认 Rubric 文件已加载
3. 点击 **🚀 开始评分**
4. 查看评分分布和详情

## 4. 功能详解

### 4.1 概览仪表盘

**功能：**
- 显示当前项目配置摘要
- 快速操作按钮
- 处理状态监控
- 最近项目列表

**使用要点：**
- 每次启动应用时，首先查看概览确认项目状态
- 使用快捷操作可快速进入常用功能

---

### 4.2 查重检测

**算法说明：**

| 算法 | 说明 | 适用场景 |
|------|------|----------|
| 文本相似度 | TF-IDF 向量相似度 | 报告正文 |
| 代码相似度 | 序列匹配+抽象语法树 | 代码部分 |
| 结构相似度 | 文档结构对比 | 整体布局 |
| 语义相似度 | 深度学习嵌入 | 改写内容 |

**操作流程：**

```
1. 选择提交目录
   └── 目录应包含学生 ZIP 文件
   
2. 配置检测参数
   ├── 可疑阈值：开始标记的相似度
   ├── 抄袭阈值：确认抄袭的相似度
   ├── 启用模板过滤：去除模板内容
   └── 启用语义检测：检测改写内容
   
3. 选择模板文件（可选）
   └── 上传实验报告模板，自动过滤
   
4. 开始检测
   └── 点击按钮，实时查看进度
   
5. 查看结果
   ├── 表格：每个学生的相似度数据
   ├── 统计：总体分布情况
   └── 详细：对比详情
```

**结果解读：**

| 相似度范围 | 标记 | 颜色 | 建议操作 |
|------------|------|------|----------|
| 0-59% | 正常 | 绿色 | 无需处理 |
| 60-84% | 可疑 | 黄色 | 人工复核 |
| 85-100% | 抄袭 | 红色 | 进一步处理 |

---

### 4.3 评分评估

**评分方法：**

1. **Rubric 评分**：按照预设标准逐项评分
2. **技术要点**：检查关键技术点是否覆盖
3. **代码分析**：分析代码质量和实现
4. **图像检测**：检查图片质量和完整性

**等级划分：**

| 等级 | 分数范围 | 标签 |
|------|----------|------|
| A | 90-100 | 优 |
| B | 80-89 | 良 |
| C | 70-79 | 中 |
| D | 60-69 | 及格 |
| F | 0-59 | 不及格 |

**操作流程：**

```
1. 加载/选择 Rubric
   └── 确认评分标准已正确加载
   
2. 配置评分选项
   ├── Rubric 评分
   ├── 技术要点检查
   ├── 代码深度分析
   └── 图像质量检测
   
3. 开始评分
   └── 系统自动处理所有提交
   
4. 查看结果
   ├── 等级分布图表
   ├── 学生评分列表
   └── 单个详情查看
```

**详情查看：**

点击学生列表中的任意项目，可查看：
- 各项得分详情
- 优势分析
- 不足之处
- 改进建议

### 4.4 反馈生成

**反馈风格：**

| 风格 | 特点 | 适用场景 |
|------|------|----------|
| 详细 | 完整的问题分析和建议 | 需要深入指导 |
| 标准 | 基本的反馈内容 | 常规情况 |
| 简洁 | 简明扼要的反馈 | 快速浏览 |
| 鼓励 | 侧重鼓励和正面反馈 | 基础较弱学生 |
| 技术 | 侧重技术问题分析 | 技术改进 |

**操作流程：**

```
1. 选择反馈风格
   
2. 选择输出格式
   ├── Markdown: 适合编辑
   ├── HTML: 适合打印
   └── 文本: 适合复制
   
3. 批量/单个生成
   ├── 批量：一次处理所有学生
   └── 单个：选择特定学生
   
4. 预览和编辑
   ├── 实时预览
   └── 手动调整内容
   
5. 导出
   └── 保存反馈文件
```

**使用场景：**

**操作流程：**


## 5. 常见操作

### 5.1 导入 Rubric 评分标准

Rubric 文件为 JSON 格式，包含评分标准。

1. 在设置页面点击 "Rubric 文件" 输入框旁的浏览按钮
2. 选择 `.json` 格式的 Rubric 文件
3. 点击保存

**Rubric 文件格式示例：**

```json
{
  "experiment": "汽车档位模拟器",
  "total_score": 100,
  "criteria": [
    {
      "name": "功能实现",
      "weight": 40,
      "items": [...]
    }
  ]
}
```

### 5.2 处理 ZIP 命名不规范

系统支持的 ZIP 命名格式：
- `姓名_学号.zip`
- `学号_姓名.zip`

如果命名不规范，可以：
1. 手动重命名 ZIP 文件
2. 或在设置中关闭严格的命名检查

### 5.3 导出学生反馈

1. 进入反馈生成页面
2. 选择需要导出的学生
3. 点击导出按钮
4. 选择保存位置和格式

## 6. 最佳实践

### 6.1 目录组织建议

```
教学/
├── 2026春/
│   ├── 07-car-gear/           # 实验目录
│   │   ├── 提交/              # 学生提交
│   │   ├── 结果/              # 处理结果
│   │   ├── 报告/              # 生成的报告
│   │   └── 反馈/              # 学生反馈
│   └── 08-traffic-light/
└── templates/                 # 模板文件
```

### 6.2 工作流程建议

**标准处理流程：**

```
1. 创建项目配置
   │
2. 收集学生提交
   │
3. 查重检测
   │   ├── 标记可疑提交
   │   └── 人工复核
   │
4. 评分评估
   │   ├── 查看评分分布
   │   └── 核对异常评分
   │
5. 生成反馈
   │   └── 批量生成学生反馈
   │
6. 导出报告
   │   ├── 成绩单
   │   ├── 查重报告
   │   └── 统计分析
```

### 6.3 参数调整建议

**查重阈值：**
- 首次使用建议：可疑 60%，抄袭 85%
- 发现漏报：降低可疑阈值到 50%
- 发现误报：提高抄袭阈值到 90%

**评分权重：**
- 实验类：技术要点 50%，代码质量 30%，报告 20%
- 设计类：技术要点 40%，代码质量 40%，报告 20%
